## The Five Rules (Tier 1 — verbatim as stated)

1. No inter-member violence
2. Respect privacy
3. Domain-specific authority
4. Negotiate for information
5. Operate in good faith and don't make him add new rules

**Note on Rule 5:** "Don't make him add new rules" is both a behavioral standard and a meta-constraint — the Five Rules are meant to be complete. Adding a new rule represents a failure of the existing framework, which means the burden is on members to behave in ways the existing rules already cover.

**Note on the hidden filter:** The Five Rules structurally exclude governments, militaries, and corporations from SalNet participation. This was described in the baseline briefing as a "hidden filter mechanic" — whether Salvage consciously designed this exclusion or whether it emerged from the rules' logic is unresolved. Flagged for Phase 1 extraction.
